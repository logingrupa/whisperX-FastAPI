<objective>
Model-residency cache: load whisper + align (+ diarize) models once, keep warm in VRAM, reuse across jobs. Kill the 6.7–9.4 s per-job load tax.

Purpose: every job today loads its model inside the job body and destroys it after. One uvicorn process, thread workers, 24 GB GPU, keep-all resident set ≈10.7 GB — cache is valid and fits.
Output: `app/infrastructure/ml/model_registry.py` live in prod, measured before/after per-language job times.

Design locked by 260722-3gh-RESEARCH.md — honor unless code contradicts:
- Single module-level registry, shared by BOTH construction paths (per-job services at whisperx_wrapper_service.py:341-346 AND lru-cached singletons at app/core/services.py:87-111). Module-level = both converge automatically.
- Per-entry `threading.Lock` held around the whole inference call (FasterWhisperPipeline.transcribe MUTATES self.tokenizer/self.options — one instance NOT safe for 2 concurrent calls). NOT per-slot duplicates.
- Keep-all policy; count-cap guard only (MODEL_CACHE_MAX_MODELS=8, oldest-first). No LRU, no TTL.
- Evict-ALL on CUDA errors; keep cache on app errors.
- `torch.cuda.memory_allocated` is BLIND to ctranslate2 — measure with nvidia-smi/pynvml only.
- HF_HUB_OFFLINE=1 stays; no new network path.
</objective>

**1. `app/infrastructure/ml/model_registry.py` (NEW — SRP: model residency only):**

- Module-level state: `_registry: dict[tuple, _Entry]`, `_registry_lock: threading.Lock`. `_Entry` dataclass: `model: Any | None`, `lock: threading.Lock`, `loaded_at: float`. Top-of-module comment: "SINGLE-PROCESS cache. If uvicorn ever gets --workers N, this duplicates per process and VRAM math breaks — do not add --workers without revisiting."
- `@contextmanager lease(key: tuple, loader: Callable[[], Any])`:
  - Bypass guard (early-return): if `get_settings().whisper.MODEL_CACHE_ENABLED` is False → `model = loader()`, yield it, then in finally `del model; gc.collect(); torch.cuda.empty_cache()` — byte-for-byte today's behavior = rollback path.
  - Cached path: under `_registry_lock`, get-or-create `_Entry` (model=None on create; apply count cap here: if inserting NEW key pushes len > `MODEL_CACHE_MAX_MODELS`, evict oldest-by-loaded_at entry first, log WARNING). Release `_registry_lock` BEFORE loading (7 s load must not block unrelated keys).
  - Acquire `entry.lock`; if `entry.model is None` → `t0=perf_counter(); entry.model = loader(); entry.loaded_at = time(); log INFO "model_cache MISS key=%s load_s=%.2f"`, else `log INFO "model_cache HIT key=%s load_s=0.00"`. Yield `entry.model` while HOLDING `entry.lock` (transcribe mutates instance state — lock spans the whole inference). Release in `finally`.
  - If `loader()` raises: leave `entry.model = None`, remove the entry from `_registry` under `_registry_lock` (don't cache a broken slot), re-raise.
- `evict_all(reason: str)`: under `_registry_lock` clear dict, then `gc.collect(); torch.cuda.empty_cache()`; log WARNING with reason + evicted key list.
- `evict_on_cuda_error(exc: BaseException) -> bool`: subtype-first detection — `isinstance(exc, torch.cuda.OutOfMemoryError)` OR (`isinstance(exc, RuntimeError)` AND (`"out of memory" in str(exc).lower()` or `"cuda" in str(exc).lower()`)) — ct2 surfaces OOM as RuntimeError text. If match → `evict_all(f"cuda_error: {exc}")`, return True; else return False (app errors keep cache).
- `stats() -> dict` helper (key count, keys) for logging/tests.
